# Heart Disease Prediction

This project predicts the presence of heart disease using a Machine Learning model built with Python and Scikit-learn.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Model
- Random Forest Classifier

## Accuracy
- 83.6%

## Files
- Heart_Disease_Prediction.ipynb
- README.md

## Purpose
This project was created for learning machine learning and understanding disease prediction using healthcare data.
